# Resprite test map

`Resources/Maps/_WG/Resprites/resprite_test.yml` shows every prototype that uses a resprite sprite.
Load it as an admin or host with `mapping /Maps/_WG/Resprites/resprite_test.yml`; a warp point named
`resprites` sits at `(1, 1)`, so `warp resprites` lands just west of the first column.

Items stand on steel floor two tiles apart along `x`, and the rows advance by 4 in `y`.
The map is grouped by origin and folder so related sprites sit together.

209 prototypes are on the map.
