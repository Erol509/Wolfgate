# Branding

Wolfgate's logo, window icons and the title of the Wolfgate changelog tab. `logo.png` (splash and main menu) is drawn
by hand. `Tools/_WF/Branding/WolfgateLogo/generate_icons.py` builds the icon PNGs and `icon.ico` from the source mark
next to it (needs Pillow), and `Resources/manifest.yml` points the client at them. The splash background stays black:
the engine hard-codes it. Its marked edits also rebrand the repository README and the MOTD.

`WFWindowBranding.Apply(window)` brands a window's title bar: the logo's lettering (`wordmark.png`, cut from
`logo.png` by the same script) and six-bar mark beside the header buttons (they step aside on narrow windows) and the
logo's spectrum as a 2 px rule under the header. `WFBrandBars` draws the bars in code so they stay crisp at any UI
scale. Windows opt in with one call after `InitializeComponent`.

`UiBranding` brands every titled window without opting in. `WFBrandingUIController` checks each open window every
frame (popped-out ones too) and restores its marks if anything removed, hid or faded them: `WFBrandingHeader` draws
the full logo in the middle of the title bar from over the window, so the header layout is untouched (skipped where
the badge above is already there), and `WFBrandingFooter` adds a logo strip as the last row of the window.
`Tools/_WF/Branding/UiBranding/generate_branding.py` cuts its textures from `logo.png` into
`Resources/Textures/_WF/Branding/UiBranding`.
