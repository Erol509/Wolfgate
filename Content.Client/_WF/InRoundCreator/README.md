# InRoundCreator

The character creator during a round. The Character Creator button in the game menu opens the lobby creator in a
window, so chat and the game stay usable beside it and the window pop-out button works on it. Any character can be
edited, created or deleted except the one being played, which cannot be deleted. Edits apply on the next spawn.

Picking a slot there only shows it: the selected character does not change mid-round, because the bank, safety deposit
boxes and persistence all write to the selected slot. `ServerPreferencesManager` enforces that for players who have
joined the game, so a modified client cannot switch either. Entry points: `LobbyUIController.OpenInRoundCharacterSetup`
and `InRoundCreatorWindow`, whose close button asks about unsaved edits first.
