# Humanoid

The character creator's Wolfgate controls: species picker, marking picker, hair and facial hair picker, sex selector
and the full-size description editor. They replace the stock pickers inside the upstream profile editor and feed the
same `HumanoidCharacterProfile`. Its marked edits also add custom species names and the prompt for unsaved changes.

Entry points: `WolfgateSpeciesPicker` (species cards with previews and guidebook links), `WolfgateMarkingPicker`
(markings grouped by body part, with rank and colour cards), `WolfgateSlotMarkingPicker`, `WolfgateSexSelector` and
`WolfgateDescriptionWindow`. The Mismatched parts option and the eye marking category are in Species.
