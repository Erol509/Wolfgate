# Traits

Ports Delta-V's categorized character-trait system: players select traits in the character creator, conditions gate their availability and spawn-time effects apply the selected traits.

The main entry points are the shared prototypes and condition/effect definitions in `Content.Shared/_DV/Traits`, the character creator in `Content.Client/_DV/Traits`, and spawn validation in `Content.Server/_DV/Traits`.
