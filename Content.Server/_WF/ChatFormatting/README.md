# ChatFormatting

Player chat emphasis delimiters (`|text|`, `+text+`, `^text^`) convert to BBCode tags
(`[italic]`, `[bold]`, `[font size=8]`) for all in-character channels: speech, emotes,
whispers, and subtle emotes. The conversion runs on the server after sanitization and obfuscation,
so the client renders the BBCode natively — no client-side changes are needed.

Entry point: `ChatSystem.ConvertCustomEmphasisToBBCode`, called from `SendEntitySpeak`,
`SendEntityWhisper`, `SendEntityEmote`, and `SubtleSystem.TrySendSubtle`.
