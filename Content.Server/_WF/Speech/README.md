# Speech

Wolfgate speech accents. Neo-French is a thicker take on the upstream French accent: players pick it as the
`WFNeoFrenchAccent` speech trait, and admins can add `NeoFrenchAccent` to any speaking entity.

Entry points: `NeoFrenchAccentSystem` (handles `AccentGetEvent`: applies the `WFNeoFrench` word replacements, then
rewrites letters, some at random) and `NeoFrenchAccentComponent`.

`NonHumanoidGaspSystem` swallows the gasp sound of any breather that is not a humanoid, so critters that borrow a
humanoid emote set don't suffocate in a human voice.
