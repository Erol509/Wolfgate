# Waypoints

World coordinates and shared waypoints on the radar. Every radar screen (helm, cockpit, mass scanner, gunnery, admin)
writes the cursor's and the scanner's world coordinates in its bottom right corner, in the same frame as the helm's
position readout and contact labels.

The WPT key on a helm or mass scanner radar opens the waypoint panel: type X and Y or use Pick and click the radar, then
Add saves the position for the ship (up to 16, name optional). Waypoints are kept on the grid in `WFWaypointsComponent`,
so everyone aboard sees and can delete the same list. They are drawn as cyan diamonds, pinned to the plot's edge when out
of view, and do not survive a server restart or a ship save. A position belongs to the map it was marked on; on other
maps it is greyed out and can only be deleted.

At a helm, Fly sends the autopilot to the typed coordinates and Go to a saved waypoint, through the same
`ShuttleConsoleAutopilotPositionMessage` as the map tab's Autopilot button; the ship keeps its present heading on arrival,
and manual flying cancels it as usual. A helm with an autopilot target stays awake with no living player near, so it
works for an admin ghost, on the map tab too, and carries on if the pilot leaves or dies. A mass scanner has no autopilot, so it only manages the list. Neither the panel
nor the markers appear on a console with no grid under it, such as a handheld scanner in open space.

`WFWaypointSystem` handles the requests; `ShuttleNavControl.Waypoints.cs` and `WFWaypointPanel` are the client.
