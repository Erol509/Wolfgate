# Construction

Repeat buttons (x2 to x50 and All) under the Craft button of the construction menu, for item recipes. The server
crafts the recipe back to back and stops at the first failed craft (out of materials, do-after interrupted); a new
request replaces what is left of the current run.

Entry points: `CraftRepeatButtons` and the client `CraftRepeatSystem` send a `CraftRepeatRequestEvent`; the server
`CraftRepeatSystem` runs the loop through upstream construction.

`ConstructionStartStepsTest` checks every recipe the menu can start: its first edge may only take materials and parts,
since a tool step there drops the materials and reports them missing.

A screwdriver or crowbar used on the material reclaimer opens or pries its panel instead of being recycled
(`MaterialReclaimerSystem.Tools.cs`).

Kits used on a machine (DV upgrade kits, the landing thruster conversion kit) are recorded on it and spawned back
when the machine is deconstructed (`WFKitRefundSystem`).
