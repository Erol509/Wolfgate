# Modsuits

A port of GoobStation's MODsuit implementation (its PRs 7485, 7489, 7496, 7500 and 7509). A back-worn control
unit spawns and deploys a helmet, chestplate, gauntlets and boots, then seals them one at a time. The unit
holds a MOD core behind a maintenance panel, every part of the suit has its own seal state, and modules are
installed into the unit and spend the core's charge while they run.

## How it works

- **Control unit.** `ModSuitComponent` names the theme and the four part prototypes. Parts spawn into the
  unit's `mod-parts` container on map init and are worn directly on deploy. The core sits in the `mod-core`
  item slot, behind the wires panel.
- **Sealing.** `ModSuitSystem` queues deployment and activation one part at a time at the theme's step
  time. A sealed part gains the components in its `ModSealedComponents` registry and shows its sealed
  sprite through `ModSuitSealedVisuals`; unsealing reverses both. The suit must be inactive before parts
  deploy or retract, and a suit cannot be removed while active.
- **Power.** The core is a MOD core item with its own power cell slot, so the cell can be swapped while the
  core stays bolted in. The theme and every installed module have an idle/active drain; the suit copies the
  core's charge into networked fields for the interface and the power alert, and cuts power at zero. A worn
  suit's core also charges while its wearer is inside a cyborg recharger.
- **Modules.** `ModModuleComponent` gives each module a type (passive, usable, toggle, active), complexity,
  power draw, cooldown, required parts and incompatibilities. `ModSuitSystem` installs, removes, pins and
  uses them; each module system subscribes to the module events it needs. The theme sets the complexity cap,
  the activation speed, the drain and any inbuilt modules.
- **Slowdown.** The control unit adds 5%, and a chestplate adds at most another 5%, so a suit stays at or
  below 10% total. Chestplates with a piercing coefficient above 0.6 add no slowdown, and boots never add
  any; only piercing protection decides which tier a chestplate is in.
- **Interface.** `ModSuitWindow` is the older MOD Interface Panel layout: suit and user status, a charge bar,
  the DNA-lock state, cover state, a module table with per-module icons and power/complexity columns, hardware
  rows for each part and a toggle-all control. It uses the restored `icons.rsi` icon set and sends activate,
  deploy, toggle, pin and eject messages.

Entry points: `ModSuitComponent`, `ModModuleComponent`, `ModPartComponent`, `ModThemePrototype`,
`ModSuitSystem` (parts, activation, power, modules, UI), the module systems under
`Content.Shared/_WF/Modsuits/Modules`, and `ModSuitWindow` with `ModSuitVisualizerSystem` on the client.

## Content

The standard suit, the department suits (standard, engineering, atmospheric, paramedic, security, head of
security, brig medical, research director and captain), the themed suits (contractor, corporate, syndicate,
elite, loader and mining) and the Einstein Engines emergency-response suits (Apocryphal, Inquisitory,
Praetorian and the engineering, janitorial, leader, medical and security Responsory suits) live in
`Resources/Prototypes/_WF/Modsuits`. Their sprites stay in the existing `_Goobstation` modsuit RSIs, while
the Einstein Engines suits use `_EinsteinEngines/Clothing/NanoTrasen/Modsuits`; the module icon set and the
new themed suit RSIs were imported with their `meta.json` files. A construction kit is sold from the cargo
console as `WFModsuitKit`, and John Wolfgate stocks the standard, microreactor and plasma cores. GoobStation's
Waddle, quick-carry, restraint-assist, auto-injector and standing-up support code lives under `Support`,
adapted to this codebase's status effect, solution and standing systems. PR 7509 added the utility,
magnetic-harness, kinesis, recycler, projectile-dampener and shooting-assistant module families; its radial
tool selector is ported under `RadialSelector`, and the EMP ward and glove translator reuse marked hooks in
`SharedEmpSystem`, `FlammableSystem` and `RadioSystem`.
