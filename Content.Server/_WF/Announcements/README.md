# Announcements

A roleplay announcement window for admins, beside the plain Announce button. Open it with `rpannounce` or the
RP Announce button on the Admin and Wolfgate tabs of the admin menu.

An announcement can carry a heading, a sender, a colour and a body (optionally with markup), and goes to everyone or
only the players on the admin's map. Its sound is none, the standard chime, or any `.ogg`/`.wav` under `/Audio`,
picked from a searchable list with a preview button and volume. It can also put a TCAS-style notification chip at
the top centre of each player's screen: a coloured tag, a short line, the sender and a countdown, with info, advisory,
warning or message-colour styling, optional flashing, and a duration (0 keeps it until clicked). Chat, sound and chip
can each be turned off; the window previews the chip and the chat text as they will look.

Entry points: `WFAnnounceCommand`, `WFAnnounceEui` and `WFAnnounceSystem` (checks and sends) on the server;
`WFAnnounceWindow` and `WFAnnouncementChipSystem` (draws chips) on the client; `WFAnnounceFormat` builds the chat
text for both the server and the preview.
