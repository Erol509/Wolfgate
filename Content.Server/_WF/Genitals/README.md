# Genitals

The anatomy system. Genitals are organs built from the character's anatomy profile, with shapes, sizes, colours and
arousal; clothing and undergarments decide what is exposed. It is opt-in and consent-gated: others see, examine, strip
or change anything only with the owner's consent toggles and their own Adult content toggle on. Players set anatomy in
the character creator's Anatomy tab and change it in round from the Anatomy panel; admins get anatomy verbs. Tail
markings are split into front and behind halves (the `TailSplit` art) so a tail never draws over the anatomy.

Entry points: `SharedGenitalsSystem` and `GenitalsSystem` (settings, owner requests, the privacy filter),
`GenitalOrganSystem` (organs from the profile), `GenitalConsentSystem`, `GenitalCoverageSystem`,
`SharedArousalSystem`, `SharedUndergarmentStripSystem`, `GenitalExamineSystem` and `GenitalSurgeryConditionSystem`; on
the client `AnatomyUIController`, `WolfgateGenitalEditor` and `GenitalsVisualizerSystem`. The profile is stored as
JSON in the `profile.genitals` column (`GenitalProfileJson`); `LegacyGenitalMarkings` converts the old genital
markings. `MarkingSet` caps undergarments at one top and one bottom per character (`UndergarmentLimitTest`).
