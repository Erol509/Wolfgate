# EmoteVoices

Scream and laugh selector, ported from Nova Sector. The Voice card on the character creator's Appearance tab picks the
sound a character makes when they scream or laugh; Species default keeps the species' own, and the play button (or
picking a voice) previews it. The choices save with the profile.

The catalogue is every scream and laugh a Wolfgate species already uses, plus Nova's set (Classic, Robotic, Jelly,
Raptor, Clown and so on) and a Silent option. `EmoteVoiceTest` fails when a playable species' own scream or laugh is
not one of the voices, so a new species needs its sounds added here.

Entry points: `EmoteVoicePrototype` (`emoteVoice`: emote, name, sound with optional per-sex sounds, params),
`EmoteVoiceRules` (validation and lookups shared by client and server), `EmoteVoicePicker` (the creator card) and
`EmoteVoiceSystem`. At each profile load the system lays the chosen voices over the species' emote sounds that
`VocalSystem` loaded, so every emote sound path uses them and zombies and cluwnes still override them. Sex changes,
cloning and polymorphs that keep the appearance keep the voices. A voice plays with its own params, never the species'.

The same card has a Message sound row: the chatter played when the character speaks (`SpeechComponent.SpeechSounds`).
`MessageSoundPrototype` (`wfMessageSound`: name, speechSounds) lists every set a species uses plus HardLight's (Moth,
Wawa, Gorilla, Sheleg); Moth uses HardLight's moth chatter as its species default. The profile load sets the pick, or
the species' own when there is none. `MessageSoundTest` fails when a playable species' own set is not offered.
