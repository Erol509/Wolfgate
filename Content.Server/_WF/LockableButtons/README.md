# LockableButtons

Makes a locked button or switch check access. The server used to toggle a `SignalSwitch` before, or despite, a
denied unlock, so players saw "access denied" and the linked doors opened anyway. Now `SignalSwitchSystem` raises
`SwitchPressAttemptEvent` before it fires and `LockableSwitchSystem` answers for anything with a `Lock`: a locked
button fires for someone its access reader admits and stays locked, and anyone else is denied. Unlocking it from
its verb opens it to everyone, and locking it again closes it.

Lockable buttons set `unlockOnClick: false`, so the click is the press rather than an unlock. A lock that still
unlocks on click keeps the click, and the switch only stays out of its way. On a ship, `ShipAccess` decides what
the button's reader holds. `LockableButtonAccessTest` covers it.
