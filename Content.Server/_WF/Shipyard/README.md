# Shipyard

Additions to the Frontier shipyard. Ships sold at a station with a `UsedShipMarketComponent` are copied before they
are scrapped and relisted a few minutes later as used ships, dents included (damage is saved with the grid). A resold
ship is loaded from YAML and never map-initialised, so `UsedShipReinitSystem` redoes the setup it missed: device
network addresses, wires, nav map data and charged machines such as gravity generators. The `ShipyardSystem` partials
let an NPC trader stand in for a console and register a spawned ship to an owner with a deed. Also holds the medical
responder ship voucher, the MMC Dredger (`WFDredger`), a salvage ship sold at the MMC shipyard, and the Carabela
(`WFCarabela`), a salvage frigate with a mobile drydock sold at the civilian shipyard beside the Caracara, and the
Reach (`WFReach`), a crewed civilian capital ship with a full set of departments.

The seller is paid at once. `WFHullRetireSystem` then parks the sold hull on a paused map and copies and deletes it 4 ms
per tick, so a sale doesn't stall the server. Before a copy, `ShipyardSystem.WFPruneDeadKeys` drops storage, device link
and clothing entries that point off the hull, since two of them in one dictionary would fail the save. If a copy still
fails, `ShipyardSystem.WFStripUnsavable` takes off the components that won't save and it starts over, so one bad entity
aboard doesn't lose the ship. The seller is paid either way.

`VesselShipyardTest` holds the checks that apply to every vessel grid, so ship tests belong there rather than in
tests for one ship: each vessel must load as a shuttle with every hardpoint-only gun mounted on a hardpoint.

A console charges the bank share of a price first and refuses the sale when it can't be taken, then takes the cash
share from its slot, or from the counter of a trader hosting it (`ShipyardHostCashQueryEvent`,
`ShipyardHostCashPaymentEvent`). `IronmanShipPurchaseTest` covers the rule for an Ironman, whose account is frozen.
