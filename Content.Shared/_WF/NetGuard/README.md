# NetGuard

Stops a client from crashing the server with a forged length in a net message. Several messages read a byte count
from the packet and allocate a buffer that size before reading, so a few bytes claiming 2 GB made the server allocate
2 GB. `NetGuardExt.ReadGuardedLength` reads the count and throws if it runs past the end of the packet, which the
engine turns into a disconnect.

It guards the content messages the server accepts from clients: `MsgUpdateCharacter`, `MsgUpdateConsent` and
`MsgEuiMessage`. The same flaw in engine messages (`MsgEntity`, VV, console completion) and in NetSerializer needs an
engine change and is on the engine docket.
